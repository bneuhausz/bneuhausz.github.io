Selected work

Warehouse management system

A full warehouse management system for one of the country's largest beverage-distribution operations. It spans a management application for office staff and shift leaders, plus PWAs running on handheld scanners and forklift terminals for warehouse workers — all built in Angular — backed by an ASP.NET Core API and several .NET background services. I built the module that drives the warehouse's automated sorting line, communicating with its PLC over OPC UA, and worked across the background services handling scheduled jobs and client integrations.

High-traffic public web applications

Public-facing web applications used by thousands of people daily, built and maintained as part of a long-running enterprise service. Distributed caching with Redis keeps them responsive under that load.

System integrations

Integrations between enterprise systems in .NET: SAP, message-based exchange over AMQP, REST and SOAP APIs, and file-based (CSV) interfaces with third-party software.

Stack and focus

I led the adoption of Angular across our frontend applications, and frontend modernization has been a recurring theme in my work since.

Day to day I work full-stack: ASP.NET Core on the backend and Angular on the frontend, with occasional Node.js scripts and .NET background services in the mix, backed by PostgreSQL or SQL Server depending on the project.

Lately I've been learning and evaluating Flutter, as the need for native mobile functionality comes up more and more.
